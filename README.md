# books_library_devfad
Projet de cours PHP POO MVC (DEVFAD-26-01)
### 1 Cloner le projet ou votre fork
```sh
# ou votre url du fork
git clone https://github.com/mithridatem/books_library_devfad.git 
cd books_library_devfad
```

### 2 installer les dépendances
```sh
composer require symfony/var-dumper
composer require vlucas/phpdotenv
composer install
```

### 3 Créer la BDD avec le script db.Sql

### 4 Créer un fichier .env à la racine :
```env
DATABASE_HOST=localhost
DATABASE_PORT=3306
DATABASE_NAME=books
DATABASE_USERNAME=
DATABASE_PASSWORD=
```
